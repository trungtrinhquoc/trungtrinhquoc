### 🌟 Featured Project
#### 🧚 Fairy Story Generator – Multimodal AI-Powered Fairy Tales
🔗 [GitHub Repository](https://github.com/trungtrinhquoc/fairy-story-generator)
> A modern full-stack web app that generates **personalized, kid-safe fairy tales** for children (4–10 years), complete with:
> - Engaging **text stories** (GPT-4o)
> - Beautiful **Pixar-style illustrations** (Vertex AI Imagen)
> - Natural **voice narration** in English/Vietnamese (gTTS)

**Key Highlights**:
- ⚡ Instant first scene + background parallel generation for remaining scenes
- 📊 Real-time progress tracking with smooth UI feedback
- 🖼️ High-quality 16:9 images with graceful fallbacks
- 🔊 Auto language detection & non-blocking audio synthesis
- 💾 Supabase for persistent storage of stories, images & audio
- 🛠 **Tech**: FastAPI (Python) • Next.js (TypeScript) • Google Cloud Vertex AI • Supabase

*My flagship project showcasing end-to-end Generative AI integration and delightful user experience.*
